Termo de Consentimento LGPD

Em conformidade com a Lei nº 13.709/2018 (Lei Geral de Proteção de Dados Pessoais – LGPD), autorizo a coleta, o armazenamento, o processamento e a utilização dos meus dados pessoais e biométricos fornecidos neste sistema para fins exclusivos de identificação, autenticação, controle de acesso e registro de participação em eventos.

Dados coletados:

  • Nome completo;
  • CPF;
  • Endereço;
  • E-mail;
  • Ano de nascimento;
  • Imagem facial para reconhecimento biométrico;
  • Registros de acesso contendo data e horário.

Os dados serão utilizados exclusivamente para as finalidades descritas acima, não sendo compartilhados com terceiros sem autorização legal.

O sistema utiliza mecanismos de segurança e criptografia para proteção das informações armazenadas.

O titular dos dados poderá solicitar acesso, correção ou exclusão de suas informações, conforme previsto na LGPD.

Ao aceitar este termo, o usuário autoriza o tratamento dos seus dados pessoais e biométricos para as finalidades descritas.
